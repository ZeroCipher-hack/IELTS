# Design direction

Working brand: IELTSQA. GitHub repository name: IELTS.

## Visual language
- Warm white background #FAFBF7, forest green #254F3B, restrained sage surfaces.
- Elegant serif headings, readable sans-serif body and controls.
- Speech-bubble/Q identity; no leaf, plant, mountain or wellness imagery.
- Clear academic descriptor: IELTS Academic — sinov imtihoni.
- Calm exam screens; evidence and actions dominate results screens.
- Use 16px body text and readable controls. Support mobile navigation and keyboard use.

## Main screens
1. Student dashboard: target band, latest result and next action.
2. Exam selection: complete Academic test or a single skill.
3. Exam: separate Listening, Reading, Writing and Speaking layouts.
4. Results: estimated overall band, four skill scores and priority weaknesses.
5. Detailed feedback: evidence from response, criterion and improvement example.
6. Weekly plan: seven practical tasks, completion state.
7. History: attempts and skill-by-skill comparison.
8. Admin: passages, questions, accepted answers, evidence, preview, versioned publication.

Reading: passage left, questions right. Writing: prompt left, editor right. Speaking: microphone status and interview part, with cue card only where appropriate.

No feedback or coaching during exam mode. Sample data must be identified. AI estimates must not be represented as official IELTS scores.

The first prototype is Uzbek only. UZ/EN/RU translation remains planned.
